DYNAMIC ISLAND v2.7.0 — остров как на iPhone, только для Windows
================================================================

ЧТО ЭТО
  Чёрная «таблетка» сверху по центру экрана. Живёт в трее, ничего не ставит.
  Сама превращается в:  плеер с текстом песен · быстрые сайты · загрузку ПК
  (процессор, видеокарта, память, сеть, температуры) · микшер громкости по
  приложениям · буфер обмена · полку для файлов · погоду с выбором городов ·
  дела и события · таймер и помодоро · индикатор громкости и зарядки.
  Стекло (Liquid Glass) рисует сам остров: при открытии он делает снимок
  того, что за ним, размывает его и кладёт под тонировку внутрь панели.
  Отдельных окон нет, поэтому у стекла нет «рамок» и краёв — оно точно
  повторяет форму острова на каждом кадре анимации. В свёрнутом виде
  остров почти непрозрачный (как у iPhone). Морфинг на пружинной физике.
  Панель большая (660 x 520), цветная подсветка и содержимое занимают её
  всю высоту, без «пустых» нижних краёв.

  ЧТО НОВОГО В 2.7
  • Обновление прямо из острова. Остров сам смотрит на GitHub, есть ли
    новая версия (через 30 секунд после запуска и потом раз в 6 часов).
    Если есть, в пилюле появится «Доступно обновление X.Y.Z». Нажми на
    пилюлю: откроется окно с описанием версии. Дальше «Обновить» (или
    «Позже» / «Пропустить версию»). Можно выбрать папку установки кнопкой
    «Изменить…». Остров скачивает, проверяет файлы, делает копию старой
    версии (%LOCALAPPDATA%\DynamicIsland\backup, три последние), ставит новую и
    сам перезапускается. При ошибке всё откатывается назад
  • Проверить вручную: вкладка «Ещё», кнопка «Обновления» (слева внизу), или
    значок в трее, «Проверить обновления». Автопроверку можно выключить там же
    (или  "updAuto": false  в settings.json)

ТРЕБОВАНИЯ
  • Windows 10 (1803 и новее) или Windows 11
  • Больше ничего: PowerShell 5.1 и .NET уже есть в Windows
  • Интернет нужен только для погоды, текста песен, календаря и обложек
    (без него остров работает)


УСТАНОВКА И ЗАПУСК (3 шага)
  1. Распакуй ZIP в постоянную папку, например  C:\Tools\DynamicIsland
     ВАЖНО: именно распаковать (ПКМ → «Извлечь всё»), а не запускать из архива.
     Папку не переноси и не удаляй, пока остров нужен.

  2. Если Windows пометила файлы как скачанные из интернета:
     выдели все файлы → ПКМ → Свойства → внизу галочка «Разблокировать» → OK.
     (Проще одной командой в PowerShell:
      Get-ChildItem C:\Tools\DynamicIsland -Recurse | Unblock-File )

  3. Двойной клик по  «Dynamic Island.vbs».
     Через секунду сверху по центру выпрыгнет пилюля, в трее появится
     маленькая иконка-таблетка. Окно консоли НЕ появляется — так и задумано.

  Включить автозапуск: открой остров → вкладка «Ещё» → «Автозапуск с Windows».
  (или ПКМ по иконке в трее → «Запускать при входе в Windows»)


КАК ПОЛЬЗОВАТЬСЯ
  Клик по острову ............ развернуть панель
  Закрыть панель ............. клик мимо острова · крестик · клик по иконке в трее
  Наведи на пустой остров .... он «вздохнёт» и покажет часы
  ПКМ по иконке в трее ....... меню: развернуть, автозапуск, логи, выход

  Вкладка «Музыка»
    Работает с любым плеером, который показывает медиа-карточку Windows:
    Spotify, Яндекс Музыка, YouTube/Twitch в Chrome/Edge/Firefox, VLC, foobar...
    • ⏮ ⏯ ⏭ — управление треком. Команды идут именно тому плееру,
      который показан в острове. Пауза и смена трека видны в пилюле
      сразу: при паузе вместо эквалайзера появляется значок паузы,
      название приглушается
    • полоса прогресса: клик или перетаскивание — перемотка (если плеер это
      позволяет); пока наводишь, над полосой показывается время
    • ползунок снизу — громкость Windows (клик, перетаскивание или колёсико
      мыши, шаг 3%), значок динамика — выключить звук
    • в свёрнутом виде: обложка + название + эквалайзер; цвет стекла берётся
      из обложки
    • справа — ТЕКСТ ПЕСНИ (база LRCLIB). Если у текста есть тайминги,
      текущая строка подсвечивается и сама встаёт по центру; крути колёсико
      над текстом, чтобы листать — через 3.5 сек вернётся к текущей строке.
      Нет текста — значит в базе песни нет (бывает с новыми и редкими треками)
    • кнопка «Текст» справа вверху сворачивает текст: плеер встаёт по центру
      и играет без текста; нажми ещё раз — текст вернётся

  Вкладка «Сайты»
    Плитки с твоими ссылками. Клик по плитке — сайт открывается в браузере
    по умолчанию, остров сворачивается.
    • плитка «Добавить» — окошко: впиши адрес (youtube.com — https:// писать
      не нужно) и, если хочешь, название; Enter — добавить, Esc — отмена.
      Кнопка «Из буфера» подставляет скопированную ссылку.
    • «Изменить» — на плитках появляются красные «−», нажми, чтобы удалить;
      «Готово» — выйти из режима.
    • до 11 сайтов. Список хранится в settings.json (поле "sites").
    • Пока открыто окошко ввода, остров на мгновение становится активным окном
      (иначе Windows не отдаёт клавиатуру); после закрытия фокус возвращается
      в твоё приложение.

  Вкладка «Система»
    Карточки: процессор, видеокарта, оперативная память, а также скорость
    сети (вход/выход) и температуры CPU и GPU, если Windows их отдаёт
    (у многих ПК датчик температуры процессора недоступен — тогда «—»).
    Карточки процессора, видеокарты и памяти: Крупный процент,
    график за последнюю минуту, подпись (модель, VRAM, «занято X из Y ГБ»).
    Красным подсвечивается нагрузка от 90%. Данные собираются раз в секунду
    и ТОЛЬКО пока эта вкладка открыта — в остальное время остров ничего не
    считает. Нагрузка видеокарты берётся из счётчиков Windows (как в Диспетчере
    задач, нужна Windows 10 1709+ и обычный драйвер); если счётчиков нет,
    на карточке будет «—».

  Вкладка «Звук»
    Сверху — общая громкость Windows. Ниже — по строке на каждое приложение,
    которое сейчас играет звук (браузер, Spotify, Discord, игры...): свой
    ползунок, проценты и кнопка динамика (выключить звук именно этому
    приложению). Список обновляется сам. Приложение появится, как только
    начнёт воспроизводить звук.

  Вкладка «Буфер»
    Последние скопированные тексты (до 40). Клик по строке — скопировать
    снова (строка вспыхивает зелёным). Звёздочка справа — ЗАКРЕПИТЬ: такая
    строка лежит сверху, не вытесняется и хранится в settings.json (до 20).
    Поиск сверху фильтрует историю. «Очистить» стирает историю (закреплённое
    остаётся). Обычная история хранится ТОЛЬКО в памяти и пропадает при
    выходе. Пароли из менеджеров паролей не записываются.

  Вкладка «Полка»
    Бросай файлы и папки прямо на остров (даже свёрнутый, из Проводника,
    с рабочего стола, из браузера). Плитки на полке: клик — открыть,
    потяни плитку — перенесёшь файл в любое окно (мессенджер, письмо, папку),
    крестик при наведении — убрать с полки (сам файл не удаляется).
    Кнопки:
    • «Скриншот» — весь экран: в буфер обмена и в файл  %LOCALAPPDATA%\DynamicIsland\Screenshots
      (другую папку можно задать в settings.json:  "shotDir": "D:\\Снимки")
    • «Область» — системный выбор области (Win+Shift+S)
    • «Запись» — запись экрана (Win+Alt+R, Xbox Game Bar; в Параметрах
      Windows должен быть включён Game Bar)

  Вкладка «Дела»
    Верхняя карточка — ближайшее событие и сколько до него осталось.
    Строка «Событие» понимает обычные фразы:
      завтра 15:30 Созвон   ·   через 20 мин выключить чайник
      в пятницу в 19 кино   ·   25.11 12:00 врач   ·   сегодня 18 ужин
    За 5 минут и в момент события остров покажет пилюлю и издаст звук.
    «Заметки» — список дел: клик по кружку — выполнено, крестик — удалить.
    Календарь (Google/Outlook/Яндекс): в настройках календаря скопируй
    секретную ссылку в формате iCal (.ics) и вставь её во вкладке «Ещё».

  Вкладка «Погода»
    Сверху — города. «Моё место» определяется по IP. «+ Город» открывает
    поиск: набери название, выбери из списка (или Enter — первый вариант).
    Если основной поиск не отвечает, используется OpenStreetMap.
    Крестик на городе — убрать. Выбранный город запоминается.
    Показывает: сейчас, ощущается как, почасовой прогноз (8 часов),
    5 дней, ветер, влажность, УФ-индекс, давление, восход и закат.

  Вкладка «Вид»
    Акцентный цвет (эквалайзер, прогресс, подсветка), темы стекла (Авто —
    по обложке, или фиксированный оттенок), переключатель «Жидкое стекло»
    и ползунок прозрачности (меняется на лету).

  Вкладка «Ещё»
    Таймер 1 / 5 / 10 / 25 / 45 минут (идёт в свёрнутом острове, в конце —
    «Готово» и звук), помодоро (25 / 5 минут, после 4 кругов — 15),
    ссылка на календарь (ICS), горячая клавиша (разворачивает и сворачивает
    остров из любого окна: Ctrl+Alt+I по умолчанию), автозапуск,
    эквалайзер, показ зарядки, «Прятаться в полноэкранном режиме», часы
    при наведении, выключить остров.

  Сами по себе появляются
    • индикатор громкости при нажатии клавиш громкости (≈1.7 сек)
    • зарядка — на ноутбуке при подключении питания; предупреждение при ≤15%
      (на настольном ПК без батареи не показывается)
    • в играх и полноэкранном видео остров прячется сам (можно выключить)


ГОРОДА ДЛЯ ПОГОДЫ
  Теперь всё внутри острова: «Погода» → «+ Город». Править файлы не нужно.

ЕСЛИ ЧТО-ТО НЕ ТАК
  Сначала запусти  Debug.bat  — он открывает остров с видимой консолью и
  показывает ошибки. Подробный лог всегда лежит здесь:
      %LOCALAPPDATA%\DynamicIsland\island.log
  (вставь в адресную строку проводника; или ПКМ по трею → «Открыть папку с логами»).
  Если пишешь мне про проблему — приложи этот файл.

  • Остров не появляется. Запусти Debug.bat. Частая причина — файлы
    не разблокированы (шаг 2) или антивирус заблокировал PowerShell-скрипт.
  • «Выполнение сценариев отключено». Лаунчер уже запускает с
    -ExecutionPolicy Bypass, так что запускай именно «Dynamic Island.vbs»
    или Debug.bat, а не сам .ps1 двойным кликом.
  • Панель просто тёмная, фона не видно. Во вкладке «Вид» проверь, что
    «Жидкое стекло» включено, и подвинь ползунок прозрачности влево. Если
    в логе есть строка «backdrop failed» — пришли мне файл лога.
    Снимок фона делается в момент открытия: если за островом потом
    что-то поменялось (видео, другое окно) — размытие обновится при
    следующем открытии.
  • Ползунок громкости. Если громкость не меняется — в логе будет строка
    «volume set failed: …» с причиной. Пришли её мне. То же для микшера:
    «mixer set failed».
  • Нет текста песни. Остров ищет по названию и исполнителю; у новых
    или редких треков текста в базе может не быть.
  • Горячая клавиша не срабатывает. Выбери другую во вкладке «Ещё».
    Если окно с правами администратора в фокусе, Windows может не отдать
    нажатия.
  • Запись экрана (Win+Alt+R) ничего не делает. Включи Xbox Game Bar:
    Параметры → Игры → Xbox Game Bar.
  • Не открываются сайты / нет иконок. Сайты открываются браузером по
    умолчанию. Иконки подгружаются из интернета (см. «Приватность»); без
    сети вместо иконки — цветная плитка с первой буквой.
  • Остров закрыт другим окном. Он сам поднимается наверх каждые 1.5 сек.
    Поверх остаются только окна в «исключительно полноэкранном» режиме.
  • Нет обложки или трек не определяется. Плеер должен показывать
    медиа-карточку Windows (громкость → карточка с названием трека). Если
    её нет — остров плеер не увидит.
  • Остров стоит не по центру / на другом мониторе. Он живёт на основном
    мониторе. После смены разрешения сам переставится за пару секунд.
  • Остановить насильно:  Stop.bat


УДАЛЕНИЕ
  1. Stop.bat
  2. «Ещё» → выключи автозапуск (или ПКМ по трею → снять галочку)
  3. Удали папку с островом и папку  %LOCALAPPDATA%\DynamicIsland
  Больше ничего в системе не остаётся.


ФАЙЛЫ
  Dynamic Island.vbs ..... тихий запуск (его же вешаем в автозапуск)
  Debug.bat .............. запуск с консолью и логами
  Stop.bat ............... остановить остров
  DynamicIsland.ps1 ...... главный скрипт (логика, анимации, стекло)
  src\Island.xaml ........ внешний вид (разметка WPF)
  src\Worker.ps1 ......... фон: плеер, буфер обмена, батарея
  src\Net.ps1 ............ фон (три потока): погода+календарь, поиск городов, текст песен
  src\Sys.ps1 ............ фон: загрузка CPU / GPU / RAM, сеть, температуры
                           (только на вкладке «Система»)
  src\Native.cs .......... системные вызовы: снимок и размытие фона, громкость,
                           микшер приложений, окна
  src\Stop.ps1 ........... остановка


ОБНОВЛЕНИЯ (для выпуска новой версии)
  1. В DynamicIsland.ps1 поменять  $AppVersion  (например, 2.7.1).
  2. Собрать ZIP с папкой DynamicIsland и выложить на GitHub релиз с тегом
     v2.7.1 (репозиторий Drouwifn-Debug/chelka должен быть публичным),
     файл ZIP называется  DynamicIsland-v2.7.1.zip.
  3. В описание релиза добавить строку  sha256: <хэш ZIP>  (по ней остров
     проверяет, что архив скачался целым). Остальной текст описания
     показывается в окне обновления.
  Версия в теге и в $AppVersion внутри архива должны совпадать, иначе остров
  не станет устанавливать обновление.


ПРИВАТНОСТЬ
  • Остров ходит в сеть только за: погодой, геокодом и поиском городов
    (open-meteo.com, запасные — nominatim.openstreetmap.org и wttr.in), определением города по IP (ipwho.is, запасной —
    ipapi.co), текстами песен (lrclib.net: уходит название и исполнитель
    играющего трека, только пока открыта вкладка «Музыка»), обложками
    треков (Deezer, запасной — iTunes), твоим календарём по ссылке (ICS) и
    поиском обновлений (api.github.com: версия последнего релиза; сам архив
    скачивается только после твоего нажатия на «Обновить»).
  • Иконки сайтов (вкладка «Сайты») берутся у Google (www.google.com/s2/favicons):
    туда уходит только домен сайта. Не хочешь — закрой остров и в settings.json
    поставь  "favicons": false  (будут цветные плитки с буквой).
  • Снимок экрана для стекла делается и размывается локально, нигде не
    сохраняется и никуда не отправляется.
  • Содержимое буфера обмена никуда не отправляется. На диск пишутся только
    закреплённые строки (settings.json). Полка хранит пути к файлам, не сами
    файлы. Заметки, события и ссылка на календарь тоже лежат в settings.json.
  • Настройки — один файл settings.json, больше в реестре только пункт
    автозапуска (HKCU\...\Run), если ты его включил.
