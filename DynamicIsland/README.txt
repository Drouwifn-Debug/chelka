DYNAMIC ISLAND v2.3 — остров как на iPhone, только для Windows
================================================================

ЧТО ЭТО
  Чёрная «таблетка» сверху по центру экрана. Живёт в трее, ничего не ставит.
  Сама превращается в:  плеер · быстрые сайты · загрузку ПК (процессор,
  видеокарта, память) · буфер обмена · погоду · таймер · индикатор
  громкости · индикатор зарядки.
  Стекло (Liquid Glass) рисует сам остров: при открытии он делает снимок
  того, что за ним, размывает его и кладёт под тонировку внутрь панели.
  Отдельных окон нет, поэтому у стекла нет «рамок» и краёв — оно точно
  повторяет форму острова на каждом кадре анимации. В свёрнутом виде
  остров почти непрозрачный (как у iPhone). Морфинг на пружинной физике.
  Панель большая (540 x 440).

  ЧТО НОВОГО В 2.3
  • Убраны «края» вокруг стекла при раскрытии (новое размытие внутри острова)
  • Новая полоска трека: наведи — утолщается, показывает время под
    курсором; тяни ползунок — перемотка, отпустил — перемотал
  • Новый ползунок громкости: тяни / клик / колёсико мыши, проценты рядом
  • Вкладка «Сайты»: свои быстрые ссылки (добавить, удалить, иконки)
  • Вкладка «Система»: загрузка процессора, видеокарты и памяти, живые графики
  • Плавные анимации: цветные точки, вкладки (светлая плашка скользит),
    кнопки, переключатели, карточки, поля ввода

ТРЕБОВАНИЯ
  • Windows 10 (1803 и новее) или Windows 11
  • Больше ничего: PowerShell 5.1 и .NET уже есть в Windows
  • Интернет нужен только для погоды и обложек (без него остров работает)


УСТАНОВКА И ЗАПУСК (3 шага)
  1. Распакуй ZIP в постоянную папку, например  C:\Tools\DynamicIsland
     ВАЖНО: именно распаковать (ПКМ → «Извлечь всё»), а не запускать из архива.
     Папку не переноси и не удаляй, пока остров нужен.

  2. Если Windows пометила файлы как скачанные из интернета:
     выдели все файлы → ПКМ → Свойства → внизу галочка «Разблокировать» → OK.
     (Проще одной командой в PowerShell:
      Get-ChildItem C:\Tools\DynamicIsland -Recurse | Unblock-File )

  3. Двойной клик по  «Dynamic Island.vbs».
     Через секунду сверху по центру выпрыгнет пилюля, в трее появится
     маленькая иконка-таблетка. Окно консоли НЕ появляется — так и задумано.

  Включить автозапуск: открой остров → вкладка «Ещё» → «Автозапуск с Windows».
  (или ПКМ по иконке в трее → «Запускать при входе в Windows»)


КАК ПОЛЬЗОВАТЬСЯ
  Клик по острову ............ развернуть панель
  Закрыть панель ............. клик мимо острова · крестик · клик по иконке в трее
  Наведи на пустой остров .... он «вздохнёт» и покажет часы
  ПКМ по иконке в трее ....... меню: развернуть, автозапуск, логи, выход

  Вкладка «Музыка»
    Работает с любым плеером, который показывает медиа-карточку Windows:
    Spotify, Яндекс Музыка, YouTube/Twitch в Chrome/Edge/Firefox, VLC, foobar...
    • ⏮ ⏯ ⏭ — управление треком. Команды идут именно тому плееру,
      который показан в острове. Пауза и смена трека видны в пилюле
      сразу: при паузе вместо эквалайзера появляется значок паузы,
      название приглушается
    • полоса прогресса: клик или перетаскивание — перемотка (если плеер это
      позволяет); пока наводишь, над полосой показывается время
    • ползунок снизу — громкость Windows (клик, перетаскивание или колёсико
      мыши, шаг 3%), значок динамика — выключить звук
    • в свёрнутом виде: обложка + название + эквалайзер; цвет стекла берётся
      из обложки

  Вкладка «Сайты»
    Плитки с твоими ссылками. Клик по плитке — сайт открывается в браузере
    по умолчанию, остров сворачивается.
    • плитка «Добавить» — окошко: впиши адрес (youtube.com — https:// писать
      не нужно) и, если хочешь, название; Enter — добавить, Esc — отмена.
      Кнопка «Из буфера» подставляет скопированную ссылку.
    • «Изменить» — на плитках появляются красные «−», нажми, чтобы удалить;
      «Готово» — выйти из режима.
    • до 11 сайтов. Список хранится в settings.json (поле "sites").
    • Пока открыто окошко ввода, остров на мгновение становится активным окном
      (иначе Windows не отдаёт клавиатуру); после закрытия фокус возвращается
      в твоё приложение.

  Вкладка «Система»
    Три карточки: процессор, видеокарта, оперативная память. Крупный процент,
    график за последнюю минуту, подпись (модель, VRAM, «занято X из Y ГБ»).
    Красным подсвечивается нагрузка от 90%. Данные собираются раз в секунду
    и ТОЛЬКО пока эта вкладка открыта — в остальное время остров ничего не
    считает. Нагрузка видеокарты берётся из счётчиков Windows (как в Диспетчере
    задач, нужна Windows 10 1709+ и обычный драйвер); если счётчиков нет,
    на карточке будет «—».

  Вкладка «Буфер»
    Последние 6 скопированных текстов. Клик по строке — скопировать снова.
    «Очистить» — стереть историю. История хранится ТОЛЬКО в памяти и пропадает
    при выходе. Пароли из менеджеров паролей (KeePass, Bitwarden, 1Password
    и т.п.) не записываются.

  Вкладка «Погода»
    Сейчас + 3 дня. Город определяется по IP. Если определился неверно
    (VPN) — см. «Свой город» ниже.

  Вкладка «Вид»
    Акцентный цвет (эквалайзер, прогресс, подсветка), переключатель
    «Жидкое стекло» и ползунок прозрачности (меняется на лету).
    Наведи на цветную точку — она «подпрыгивает» и получает кольцо.

  Вкладка «Ещё»
    Таймер 1 / 5 / 10 / 25 / 45 минут (идёт в свёрнутом острове, в конце —
    «Готово» и звук), автозапуск, эквалайзер, показ зарядки,
    «Прятаться в полноэкранном режиме», часы при наведении, выключить остров.

  Сами по себе появляются
    • индикатор громкости при нажатии клавиш громкости (≈1.7 сек)
    • зарядка — на ноутбуке при подключении питания; предупреждение при ≤15%
      (на настольном ПК без батареи не показывается)
    • в играх и полноэкранном видео остров прячется сам (можно выключить)


СВОЙ ГОРОД ДЛЯ ПОГОДЫ
  1. Закрой остров (Stop.bat).
  2. Открой файл  %LOCALAPPDATA%\DynamicIsland\settings.json  в Блокноте
     (вставь этот путь в проводник).
  3. Найди строчку со словом city — в ней пустые кавычки "" — и впиши город
     между ними, например:  "city":  "Москва"   (кавычки оставь!)
  4. Сохрани, запусти остров снова («Dynamic Island.vbs»).


ЕСЛИ ЧТО-ТО НЕ ТАК
  Сначала запусти  Debug.bat  — он открывает остров с видимой консолью и
  показывает ошибки. Подробный лог всегда лежит здесь:
      %LOCALAPPDATA%\DynamicIsland\island.log
  (вставь в адресную строку проводника; или ПКМ по трею → «Открыть папку с логами»).
  Если пишешь мне про проблему — приложи этот файл.

  • Остров не появляется. Запусти Debug.bat. Частая причина — файлы
    не разблокированы (шаг 2) или антивирус заблокировал PowerShell-скрипт.
  • «Выполнение сценариев отключено». Лаунчер уже запускает с
    -ExecutionPolicy Bypass, так что запускай именно «Dynamic Island.vbs»
    или Debug.bat, а не сам .ps1 двойным кликом.
  • Панель просто тёмная, фона не видно. Во вкладке «Вид» проверь, что
    «Жидкое стекло» включено, и подвинь ползунок прозрачности влево. Если
    в логе есть строка «backdrop failed» — пришли мне файл лога.
    Снимок фона делается в момент открытия: если за островом потом
    что-то поменялось (видео, другое окно) — размытие обновится при
    следующем открытии.
  • Ползунок громкости. Если громкость не меняется — в логе будет строка
    «volume set failed: …» с причиной. Пришли её мне.
  • Не открываются сайты / нет иконок. Сайты открываются браузером по
    умолчанию. Иконки подгружаются из интернета (см. «Приватность»); без
    сети вместо иконки — цветная плитка с первой буквой.
  • Остров закрыт другим окном. Он сам поднимается наверх каждые 1.5 сек.
    Поверх остаются только окна в «исключительно полноэкранном» режиме.
  • Нет обложки или трек не определяется. Плеер должен показывать
    медиа-карточку Windows (громкость → карточка с названием трека). Если
    её нет — остров плеер не увидит.
  • Остров стоит не по центру / на другом мониторе. Он живёт на основном
    мониторе. После смены разрешения сам переставится за пару секунд.
  • Остановить насильно:  Stop.bat


УДАЛЕНИЕ
  1. Stop.bat
  2. «Ещё» → выключи автозапуск (или ПКМ по трею → снять галочку)
  3. Удали папку с островом и папку  %LOCALAPPDATA%\DynamicIsland
  Больше ничего в системе не остаётся.


ФАЙЛЫ
  Dynamic Island.vbs ..... тихий запуск (его же вешаем в автозапуск)
  Debug.bat .............. запуск с консолью и логами
  Stop.bat ............... остановить остров
  DynamicIsland.ps1 ...... главный скрипт (логика, анимации, стекло)
  src\Island.xaml ........ внешний вид (разметка WPF)
  src\Worker.ps1 ......... фон: плеер, буфер, батарея, погода
  src\Sys.ps1 ............ фон: загрузка CPU / GPU / RAM (только на вкладке «Система»)
  src\Native.cs .......... системные вызовы: снимок и размытие фона, громкость, окна
  src\Stop.ps1 ........... остановка


ПРИВАТНОСТЬ
  • Остров ходит в сеть только за: погодой и геокодом (open-meteo.com),
    определением города по IP (ipwho.is, запасной — ipapi.co) и обложками
    треков (Deezer, запасной — iTunes), если плеер сам не дал обложку.
  • Иконки сайтов (вкладка «Сайты») берутся у Google (www.google.com/s2/favicons):
    туда уходит только домен сайта. Не хочешь — закрой остров и в settings.json
    поставь  "favicons": false  (будут цветные плитки с буквой).
  • Снимок экрана для стекла делается и размывается локально, нигде не
    сохраняется и никуда не отправляется.
  • Содержимое буфера обмена никуда не отправляется и на диск не пишется.
  • Настройки — один файл settings.json, больше в реестре только пункт
    автозапуска (HKCU\...\Run), если ты его включил.
