# Dynamic Island для Windows

Остров как на iPhone, только для ПК: пилюля сверху экрана, которая раскрывается в панель
с плеером, быстрыми сайтами, загрузкой ПК, буфером обмена, погодой и таймером.
Windows 10 / 11, PowerShell 5.1 + WPF, ничего устанавливать не нужно.

## Запуск
1. Скачай репозиторий (Code → Download ZIP), распакуй в постоянную папку.
2. Открой папку `DynamicIsland`, выдели все файлы → ПКМ → Свойства → «Разблокировать».
3. Двойной клик по `Dynamic Island.vbs`.

Подробная инструкция — в [`DynamicIsland/README.txt`](DynamicIsland/README.txt).
Если что-то не работает: запусти `Debug.bat` и пришли файл `%LOCALAPPDATA%\DynamicIsland\island.log`.

## Что нового в v2.3
- Стекло рисует сам остров (размытый снимок фона внутри панели): никаких рамок и «краёв» при раскрытии
- Новая полоска трека (время под курсором, перетаскивание) и рабочий ползунок громкости
- Вкладка «Сайты» — свои быстрые ссылки
- Вкладка «Система» — загрузка процессора, видеокарты и памяти
- Плавные анимации: цветные точки, вкладки, кнопки, переключатели, карточки
