# Dynamic Island для Windows

Остров как на iPhone, только для ПК: пилюля сверху экрана, которая раскрывается в панель
с плеером и текстом песни, быстрыми сайтами, загрузкой ПК, буфером обмена, погодой, таймером и не только.
Windows 10 / 11, PowerShell 5.1 + WPF, ничего устанавливать не нужно.

## Запуск
1. Скачай репозиторий (Code → Download ZIP), распакуй в постоянную папку.
2. Открой папку `DynamicIsland`, выдели все файлы → ПКМ → Свойства → «Разблокировать».
3. Двойной клик по `Dynamic Island.vbs`.

Подробная инструкция и список возможностей — в [`DynamicIsland/README.txt`](DynamicIsland/README.txt).
Если что-то не работает: запусти `Debug.bat` и пришли файл `%LOCALAPPDATA%\DynamicIsland\island.log`.

## Обновления
Остров сам смотрит на GitHub, есть ли версия новее (через 30 секунд после запуска и раз в 6 часов).
Если есть, в пилюле появится «Доступно обновление»: нажми на неё, выбери папку и «Обновить».
Вручную: вкладка «Ещё» → «Обновления» или значок в трее. Версия берётся из тегов `vX.Y.Z` (и релизов) этого репозитория.
